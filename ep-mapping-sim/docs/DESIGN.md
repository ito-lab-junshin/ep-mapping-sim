# EP Mapping Simulator 設計書

不整脈アブレーションの 3D マッピング教育シミュレータ。ブラウザだけで動き、GitHub Pages で公開する。

- 対象ユーザー：臨床工学技士の学生、若手メディカルスタッフ（将来は研究用途へ拡張）
- 開発主体：伊藤朋晃（純真学園大学）
- 実装：React + Vite + TypeScript + Three.js（react-three-fiber）+ zustand
- 本書は「何を・なぜ・どこまで」を決める文書。実装の手順は `CLAUDE.md` を参照。

---

## 1. 目的と到達目標

学生が、実機に触れる前に次の流れを一通り体験できること。

1. 不整脈の種類を選ぶ
2. 心腔のジオメトリーを作る（収集モード／プリセット）
3. カテーテルを置き、心内心電図（EGM）が位置に応じて変わることを確認する
4. 頻拍を誘発し、活性化（LAT）マップで機序を読む
5. エネルギーを選んで通電し、ブロック／隔離／非誘発を確認する
6. 同じ症例を CARTO 風・EnSite 風・OPAL HDx 風の画面で見比べ、画面が違っても電気生理は同じだと理解する

**非目標（v1 では作らない）**：透視画像、心室性不整脈、合併症（タンポナーデ・横隔神経麻痺など）、実機と同じアルゴリズムの再現、臨床判断の代替。

## 2. 全体アーキテクチャ

```
┌───────────────────────────────────────────────────────────────┐
│ UI 層（React）                                                 │
│  ControlPanel / EgmPanel / CatheterTray / AblationConsole      │
│  → テーマ・用語・機能フラグは src/systems から受け取る           │
├───────────────────────────────────────────────────────────────┤
│ 3D 層（react-three-fiber）                                     │
│  Scene / ChamberMesh / CatheterModel / LesionMarkers           │
│  → マウス操作（raycast）でカテーテル配置・ポイント収集            │
├───────────────────────────────────────────────────────────────┤
│ 状態（zustand）src/state                                        │
│  選択中システム・不整脈・エネルギー・カテーテル・病変・調律状態   │
├───────────────────────────────────────────────────────────────┤
│ コア（純 TypeScript・UI 非依存・単体テスト可）src/core           │
│  geometry   : メッシュ生成・隣接リスト・領域ラベル               │
│  propagation: セルオートマトン（興奮伝播）                      │
│  egm        : 電極位置 → EGM 波形                               │
│  arrhythmia : 不整脈シナリオ（基質・誘発・根治判定）             │
│  ablation   : エネルギー別の病変モデル                          │
└───────────────────────────────────────────────────────────────┘
```

設計原則：

- **コアは UI を知らない。** `src/core` は Three.js にも React にも依存しない。研究用途で Node.js からバッチ実行できるようにするため。
- **システムの違いは「設定」で表す。** 3 システムの差は `src/systems/index.ts` のテーマオブジェクト（配色・用語・機能フラグ）に閉じ込める。UI コンポーネントが `if (system === 'carto')` と書くのは禁止。
- **ハイブリッド構成。** 伝播と EGM は物理寄り（セルオートマトン）、頻拍の「誘発できたか」「根治したか」はシナリオごとのルールで判定する。見た目の説得力と判定の確実さを両立するため。

## 3. データモデル（`src/core/types.ts`）

| 型 | 役割 |
|---|---|
| `SurfaceMesh` | 心腔の三角形メッシュ。頂点がセルオートマトンの「セル」。頂点ごとに解剖領域ラベルをもつ |
| `TissueState` | 頂点ごとの phase／不応期／伝導速度／viability／voltage |
| `Catheter` / `Electrode` | 電極の 3D 位置と接触頂点。双極の組み合わせ |

## 4. 興奮伝播モデル（`src/core/propagation`）

### 4.1 セルオートマトン

- 各頂点は 静止(0) → 興奮・絶対不応(1) → 相対不応(2) → 静止(0)。
- 興奮した頂点は隣接頂点へ `距離 / 伝導速度` の遅延で到達予定時刻を書き込む。
- `viability = 0` の頂点は興奮せず、伝播を遮断する（病変・解剖学的障壁）。
- 刻み幅 2 ms。実時間 1 秒 ＝ シミュレーション 1 秒を基本とし、スロー再生も用意する。

### 4.2 既定パラメータ（教育用の目安。研究用途ではシナリオ側で上書き）

| 部位 | 伝導速度 mm/ms | ERP ms | 備考 |
|---|---|---|---|
| 一般心房筋 | 0.8 | 250 | |
| CTI（峡部） | 0.3〜0.5 | 230 | 粗動の旋回を成立させる遅伝導 |
| 遅伝導路（AVNRT） | 0.1 | 200 | 速伝導路より ERP を短く |
| 速伝導路（AVNRT） | 1.5 | 320 | |
| 副伝導路（WPW） | 2.0 | 280 | 弁輪上の 1〜3 頂点に限局 |
| PV 筋スリーブ | 0.5 | 180 | AF トリガーの発火元 |
| 心房中隔 | 0.6 | 250 | |

### 4.3 研究用途への拡張口

`CellularAutomaton` の公開 API は `stimulate()` / `step()` / `reset()` のみ。将来この層を反応拡散モデル（FitzHugh–Nagumo、Aliev–Panfilov）に置き換えられるようにする。

## 5. 不整脈シナリオ（`src/core/arrhythmia`）

各シナリオは 3 つの関数と学習ゴールをもつ。

### 5.1 心房細動（AF）— PVI

- 心腔：LA（4 本の PV 口、LAA、僧帽弁輪をもつ解剖モデル）
- 基質：PV 内の 1 頂点以上を「トリガー」とし、周期 150〜250 ms でランダム発火。心房筋の ERP を 160〜200 ms に短縮し、複数波の旋回を成立させる
- 誘発：トリガー発火で自動開始（バースト刺激でも可）
- 根治判定：各 PV 口を一周する経路に `viability = 0` の連続した閉曲線があること（entrance block）。加えて PV 内頂点を刺激しても LA 本体に伝わらないこと（exit block）
- 学習ゴール：環状カテーテルで PV 電位を見る → 隔離線 → exit block 確認

### 5.2 通常型心房粗動（CTI 依存性）

- 心腔：RA（三尖弁輪、CTI、CS 口、IVC、SVC、分界稜）
- 基質：CTI の伝導速度を下げ、分界稜を機能的ブロック線にする。三尖弁輪を反時計方向に旋回する単一波を初期条件として投入
- 誘発：CS 口からのバースト刺激（周期 200〜250 ms）
- 根治判定：三尖弁輪から IVC までを結ぶ `viability = 0` の連続線があり、CS 口刺激で反時計回り、低位外側 RA 刺激で時計回りの伝導が線を越えない（両方向性ブロック）
- 学習ゴール：CS 近位→遠位の順序・ハロー電極で方向確認 → 連続線 → 両方向性ブロック確認

### 5.3 AVNRT（遅伝導路、通常型）

- 心腔：RA（Koch 三角：His 束電位記録部位、CS 口、三尖弁輪中隔側）
- 基質：Koch 三角に速伝導路（前上方、ERP 長い）と遅伝導路（後下方、伝導遅い・ERP 短い）を設定し、両者が房室結節共通路で合流する簡易 2 経路モデル
- 誘発：心房期外刺激（S1 600 ms、S2 を 10 ms 刻みで短縮）。速伝導路 ERP に達すると遅伝導路経由となり AH 間隔がジャンプ（≥ 50 ms）、エコーで頻拍が始まる
- 根治判定：遅伝導路の頂点に病変があり、同じプロトコルで非誘発。通電中に接合部調律（周期 500〜700 ms）を出し、教育的フィードバックとする
- 学習ゴール：His 記録 → jump 確認 → 遅伝導路通電 → 接合部調律と非誘発

### 5.4 WPW（副伝導路）

- 心腔：LA（左側副伝導路、既定は左側自由壁。右側・中隔はオプション）
- 基質：弁輪上の 1〜3 頂点に心房—心室を直結する副伝導路。洞調律では心室側へ早期伝導（デルタ波）、心房期外刺激で副伝導路の順行性 ERP に達すると房室結節経由で心室に至り、副伝導路を逆行して順行性 AVRT を開始
- 誘発：心房期外刺激または心室刺激
- 根治判定：副伝導路頂点が `viability = 0`。デルタ波消失、同プロトコルで非誘発
- 学習ゴール：弁輪多極カテーテルで最早期部位 → AV（または VA）融合部位 → 通電後の消失確認

### 5.5 心室と体表 ECG の扱い

心室はメッシュを持たせず、「房室結節／副伝導路を通過した興奮が一定遅延後に心室を興奮させる」1 コンパートメントで表す。体表 ECG は P 波・QRS・デルタ波のテンプレート合成とし、EGM パネルの最上段に出す。

**誘導数はユーザーが選択できる**（操作パネルの「体表 ECG」）。

| 選択肢 | 内容 | 実装 Phase |
|---|---|---|
| 1 誘導 | II のみ | 1 |
| 3 誘導（既定） | I・II・V1。AFL の鋸歯状波（II）、WPW のデルタ波極性（I・V1）を教えるため | 1 |
| 12 誘導 | 心室 1 コンパートメントでは局在の根拠が薄いため、心室の簡易ベクトルモデル導入後に実装。それまでは選択肢に「準備中」と表示 | 7 |

### 5.6 刺激プロトコルの既定値（教科書的な値）

| 項目 | 既定値 |
|---|---|
| S1 | 600 ms × 8 拍 |
| S2 開始・刻み | S1 − 100 ms から 10 ms 刻みで短縮（ERP または誘発まで） |
| S3 | 任意追加、S2 と同じ刻み |
| バースト | 300 ms → 200 ms、10 ms 刻み、各 10 拍 |
| 刺激部位の既定 | AF: CS 近位／AFL: CS 口／AVNRT: HRA／WPW: HRA（心室刺激は RV） |

値は操作パネルで変更でき、変更内容は URL パラメータに保存して授業で共有できるようにする。

## 6. 心内心電図（`src/core/egm`）

- **単極電位**：電極の接触頂点周辺（近傍 2 リング）で、活性化からの経過時間に対する RS 型テンプレートを距離重み付きで加算
- **双極電位**：2 電極の単極差分
- **遠隔電位**：全頂点から距離の 2 乗で減衰する成分を加える。非接触電極は遠隔電位のみ（鈍い低振幅）
- **部位特性**：PV 電位（鋭い高周波成分、心房電位との二峰）、遅伝導路（分裂電位）、AF（fractionation、頂点の不規則な活性化の自然な帰結）
- **表示**：Canvas 2D でスクロール描画。スイープ速度 25／50／100／200 mm/s、ゲイン可変、キャリパー計測（AH・HV・サイクル長）。チャンネル順は体表 ECG → HRA → HIS → CS 9-10 … 1-2 → ABL d/p → RV

## 7. アブレーション（`src/core/ablation`）

| エネルギー | デバイス | 操作 | 病変モデル（教育用近似） |
|---|---|---|---|
| RF | 先端 3.5 mm 灌流 | 出力 25〜50 W、時間、接触圧（CF 対応テーマのみ表示） | 病変半径 ≈ 1.5 + (出力^0.6 × 時間^0.3 × 接触^0.3)/12 mm（2〜8 mm）。Ablation Index 風の指標 |
| クライオ | 28 mm バルーン | PV 口への当て方（閉塞度 0〜1）、最低温度、時間 | 閉塞度が高いほど PV 口を一周する病変。time-to-isolation を表示 |
| PFA | バスケット／フラワー | PV 口に当てて通電（形状 2 種、回数） | 直径 18〜24 mm の広く浅い病変が瞬時に完成。心筋選択性のため「周辺構造への影響なし」の説明を添える |

病変の適用：中心頂点からの距離に応じて `viability` と `voltage` を下げ、中心付近は `viability = 0`（伝導遮断）。

**注意**：上の式・数値は文献値の目安をもとにした教育用の近似で、各社の製品アルゴリズムとは無関係。画面には「教育用モデル」である旨を常時表示する。

## 8. マッピングシステムの切り替え（`src/systems`）

### 8.1 方針

- CARTO®（Biosense Webster / J&J MedTech）、EnSite™（Abbott）、OPAL HDx™（Boston Scientific）は各社の商標。本アプリは非公式・教育目的で、各社と無関係。
- 再現するのは**公開情報から受ける画面の印象（配色・用語・レイアウト）と、学習上意味のある機能の有無**。内部アルゴリズムは再現しない。
- 3 テーマで**同じ症例・同じカテーテル・同じ病変**が再現できる。差が出るのは表示と補助指標のみ。

### 8.2 テーマの構成要素

| 要素 | CARTO 風 | EnSite 風 | OPAL HDx 風 |
|---|---|---|---|
| ジオメトリー収集の呼称 | FAM（高速解剖マップ） | 高密度収集 | ジオメトリ収集 |
| 活性化マップの色順 | 赤→黄→緑→青→紫 | 白→赤→黄→緑→青→紫 | 赤→黄→緑→青→紫 |
| 病変タグ | VisiTag 風（指標到達で自動） | AutoMark 風 | 病変タグ |
| 接触圧表示 | あり | あり | なし |
| 局所インピーダンス | なし | なし | DirectSense 風 |
| 病変指標 | Ablation Index 風 | なし（時間・出力・CF の表示） | 局所インピーダンス低下量 |
| 多極カテーテル | 多極スプライン（PentaRay 風） | グリッド型（HD Grid 風）＋方向非依存 EGM 風 | 多極スプライン |
| ボルテージ閾値スライダ | あり | あり | あり |

機能フラグは `SystemTheme.features` に集約。UI は `theme.features.xxx` を見て要素を出し分ける。

## 9. ジオメトリー作成

### 9.1 プリセットモード

**方針：まずパラメトリック自作、後で公開 3D モデルへ差し替え可能にする。**

- Phase 2 では `src/core/geometry/parametric/` に数式で LA（楕円体＋PV 4 本の管状突起＋LAA＋僧帽弁輪の開口）と RA（楕円体＋SVC/IVC＋三尖弁輪の開口＋CS 口）を生成する。頂点ごとの領域ラベル（PV 口、LAA、僧帽弁輪、CTI、Koch 三角、CS 口、分界稜など）は生成時に確実に付与できる。
- メッシュの読み込み口は `ChamberLoader` インターフェースに統一し、glTF ローダ（公開モデル、Blender で切り出し・ポリゴン削減・ラベル付け）を後から追加できるようにする。公開モデルを使う場合はライセンス（CC BY など）を `docs/ASSETS.md` に記録する。
- v0.1 は楕円体のプレースホルダ。

### 9.2 収集モード（FAM 風）
- 隠しメッシュ（プリセット）を「真の解剖」として保持し、ユーザーのカテーテル電極が触れた点を収集する
- 収集点から表示メッシュを段階的に構築（点が少ないときは粗い凸包、増えるにつれて真の形に近づく）
- 内部の電気生理計算は常に隠しメッシュ上で行い、表示メッシュへ投影する。これにより「マップが粗くても電気生理は正しい」状態を保てる

## 13. 検証

- `src/core` は vitest で単体テスト（伝播が全頂点に届く、病変が遮断する、各シナリオで誘発→根治が成立する、など）
- 電気生理の妥当性は不整脈専門医・経験豊富なメディカルスタッフのレビューで確認し、`docs/REVIEW_LOG.md` に記録する
- 既知の単純化と限界は `docs/LIMITATIONS.md` に列挙し、アプリ内「このシミュレータについて」からリンクする
