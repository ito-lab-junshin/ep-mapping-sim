# QA の記録（チュートリアルの通し操作・E2E で見つかった不具合）

専門家レビュー（`REVIEW_LOG.md`）とは別に、画面の操作の流れの確認で見つかったことを残す（docs/DESIGN.md §13）。
対応の方針（伊藤先生と決定）：不具合と文言はその場で直して記録する。動き・判定の基準・電気生理の値を変える必要があるものは、先生に確認してから直す。

## 2026-11-15　E2E の作成と、チュートリアル 5 本の通し操作

### 方法

- E2E（`npm run e2e`、17 本）：本番と同じビルドを Chromium で開き、画面のボタン・選択・表示は本物の操作で確かめた。3D 上のカテーテル操作と時間の早送りだけテスト用の口（`?e2e=1` の `window.__ep`）を使った
- 通し操作：画面の指示とヒントだけを頼りに、マウスで操作した（3D 上のクリック・ドラッグ、カテーテルの選択、領域の名前のホバー）。時間は実時間で進めた（刺激プロトコル 1 回に 1〜3 分）。画面写真で手順ごとに確認した
  - PVI（RF）：4 本の PV の一周の通電（約 60 点）だけテスト用の口で行った（LSPV の 16 点は手で通電した。下の所見 7）。ほかは手で操作した
  - 通常型 AFL（反時計回り）・AVNRT・WPW：すべて手で操作した
  - 通常型 AFL（時計回り）：反時計回りと同じ画面・手順なので、E2E だけで確かめた

### 先生に確認したいこと（2026-11-15 に回答をいただき、上のとおり対応した）

1. AVNRT の遅伝導路の標的（所見 13）：入口を 1 頂点のまま、領域の表示を半径 3 mm 程度に小さくするか。入口を領域（例：半径 3〜4 mm の頂点の集まり）にして、その大半が焼ければ遅伝導路の伝導が消えるようにするか
2. WPW の副伝導路の標的（所見 14）：付着部を 1 頂点にするか、2 頂点を近づけるか、2 頂点のどちらかが焼ければ伝導が途絶えるようにするか（副伝導路は 1 本の束なので、どちらかで途絶えるのが自然）
3. 頻拍中の通電（所見 15）：チュートリアルで、通電の前に頻拍を止める（例：刺激をやめて待つ・オーバードライブ刺激）よう案内するか。頻拍中でも通電はできるままにするか

## 2026-11-16　新しいチュートリアル 4 本の通し操作

### 方法

- 対象：PVI（クライオバルーン）・PVI（PFA）・AF（SVC トリガー）・持続性 AF（天蓋の低電位領域）
- 画面の指示とヒントだけを頼りに、マウスで操作した（症例・AF の型・エネルギー・標的の PV・押し付けの選択、3D 上のクリック、ホバーでの領域名、視点のボタン、通電・待機・刺激・根治判定のボタン、隙間のヒント）。手順ごとに画面写真で確かめた
- 時間は実時間で進めた。ただし持続性 AF の RF の PVI（4 本の一周）だけテスト用の口で行った（RF の PVI は 2026-11-15 に手で確かめた操作。持続性 AF のクライオの PVI は手で行い、下の所見 27 を見つけた）。SVC の隔離の確かめ直し（所見 24）でも PVI はテスト用の口で行った
- 結果：クライオ・PFA・持続性 AF（RF の PVI）は最後まで完了した。SVC トリガーは所見 24 の案内を足して確かめ直し、隔離と AF の停止を確認した。エラーは出なかった
