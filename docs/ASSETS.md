## 現在の解剖モデル

- パラメトリック形状（`src/core/geometry/parametric`）：数式で生成したもので、外部のアセットは使っていない
- glTF ローダ（Phase 7）は実装済み。使う公開モデルは別途選定する。選んだら、上の表にライセンス（CC BY など）と、
  Blender での加工（切り出し・ポリゴン削減・LA／RA の分割・開口の切り抜き）と、領域ラベル JSON の作り方（半自動推定＋手直し）を書く

## glTF のモデルを用意するときの決まり

- 座標系：+x = 患者の左、+y = 頭側、+z = 前方（アプリと同じ）。単位はメートル（glTF の規約）か mm（ラベル JSON の `unit`）
- LA と RA を別のメッシュにし、名前を `LA`・`RA` にする（またはラベル JSON の `chambers` で指定）
- 弁輪・PV・大静脈・CS 口は穴として切り抜く（LA は僧帽弁輪と 4 本の PV の 5 つ、RA は三尖弁輪・SVC・IVC・CS 口の 4 つ）
- 出発点：`npm run export-gltf -- normal 出力.glb 出力.labels.json` でパラメトリックモデルを書き出せる
