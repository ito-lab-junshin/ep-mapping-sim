# EP Mapping Simulator 設計書

不整脈アブレーションの 3D マッピング教育シミュレータ。ブラウザだけで動き、GitHub Pages で公開する。

- 対象ユーザー：臨床工学技士の学生、若手メディカルスタッフ（将来は研究用途へ拡張）
- 開発主体：伊藤朋晃（純真学園大学）
- 実装：React + Vite + TypeScript + Three.js（react-three-fiber）+ zustand
- 本書は「何を・なぜ・どこまで」を決める文書。実装の手順は `CLAUDE.md` を参照。

---

## 1. 目的と到達目標

学生が、実機に触れる前に次の流れを一通り体験できること。

1. 不整脈の種類を選ぶ
2. 心腔のジオメトリーを作る（収集モード／プリセット）
3. カテーテルを置き、心内心電図（EGM）が位置に応じて変わることを確認する
4. 頻拍を誘発し、活性化（LAT）マップで機序を読む
5. エネルギーを選んで通電し、ブロック／隔離／非誘発を確認する
6. 同じ症例を CARTO 風・EnSite 風・OPAL HDx 風の画面で見比べ、画面が違っても電気生理は同じだと理解する

**非目標（v1 では作らない）**：透視画像、心室性不整脈、合併症（タンポナーデ・横隔神経麻痺など）、実機と同じアルゴリズムの再現、臨床判断の代替。

## 2. 全体アーキテクチャ

```
┌───────────────────────────────────────────────────────────────┐
│ UI 層（React）                                                 │
│  ControlPanel / EgmPanel / CatheterTray / AblationConsole      │
│  → テーマ・用語・機能フラグは src/systems から受け取る           │
├───────────────────────────────────────────────────────────────┤
│ 3D 層（react-three-fiber）                                     │
│  Scene / ChamberMesh / CatheterModel / LesionMarkers           │
│  → マウス操作（raycast）でカテーテル配置・ポイント収集            │
├───────────────────────────────────────────────────────────────┤
│ 状態（zustand）src/state                                        │
│  選択中システム・不整脈・エネルギー・カテーテル・病変・調律状態   │
├───────────────────────────────────────────────────────────────┤
│ コア（純 TypeScript・UI 非依存・単体テスト可）src/core           │
│  geometry   : メッシュ生成・隣接リスト・領域ラベル               │
│  propagation: セルオートマトン（興奮伝播）                      │
│  egm        : 電極位置 → EGM 波形                               │
│  arrhythmia : 不整脈シナリオ（基質・誘発・根治判定）             │
│  ablation   : エネルギー別の病変モデル                          │
└───────────────────────────────────────────────────────────────┘
```

設計原則：

- **コアは UI を知らない。** `src/core` は Three.js にも React にも依存しない。研究用途で Node.js からバッチ実行できるようにするため。
- **システムの違いは「設定」で表す。** 3 システムの差は `src/systems/index.ts` のテーマオブジェクト（配色・用語・機能フラグ）に閉じ込める。UI コンポーネントが `if (system === 'carto')` と書くのは禁止。
- **ハイブリッド構成。** 伝播と EGM は物理寄り（セルオートマトン）、頻拍の「誘発できたか」「根治したか」はシナリオごとのルールで判定する。見た目の説得力と判定の確実さを両立するため。

## 4. 興奮伝播モデル（`src/core/propagation`）

### 4.1 セルオートマトン

- 各頂点は 静止(0) → 興奮・絶対不応(1) → 相対不応(2) → 静止(0)。
- 興奮した頂点は隣接頂点へ `距離 / 伝導速度` の遅延で到達予定時刻を書き込む。
- 到達予定はイベントとして時刻順に処理し、刻み幅の途中の正確な時刻で興奮させる。あわせて、辺を共有する三角形の第 3 頂点がすでに興奮していれば、その辺上から直進する経路も候補にする（三角形更新。eikonal 方程式の fast marching 法と同じ考え方）。これにより、到達時刻 × 伝導速度と表面距離の差は 5 % 以内になる（Phase 2 までは刻み幅への丸めと辺に沿ったジグザグ経路のため、実効の伝導速度が設定値より 18〜40 % 遅かった）
- 異方性：両端の頂点が線維方向と長軸方向の伝導速度をもつ辺は、楕円則 1/cv² = cos²θ/cvL² + sin²θ/cvT² で伝導速度を決める（θ = 辺と線維のなす角、cvT = 横方向 = `conductionVelocity`）
- 心房間の連結（`SurfaceMesh.bridges`）は連結ごとの伝導速度 `cvMmPerMs` で伝える
- `viability = 0` の頂点は興奮せず、伝播を遮断する（病変・解剖学的障壁）。
- 刻み幅 2 ms。実時間 1 秒 ＝ シミュレーション 1 秒を基本とし、スロー再生も用意する。

## 5. 不整脈シナリオ（`src/core/arrhythmia`）

各シナリオは基質（`setupSubstrate`）、推奨の誘発法（`induction`）、構造的な根治の基準（`structuralChecks`）と学習ゴールをもつ。誘発と「同じプロトコルで非誘発」は `common.ts` の `tryInduce` / `verifyCure` で、複製したエンジンに刺激プロトコルを走らせて判定する。テスト（`src/core/arrhythmia/scenarios.test.ts`）で 4 症例すべての誘発 → 治療 → 非誘発を確認している。

### 5.1 心房細動（AF）— PVI

- 心腔：LA（4 本の PV 口、LAA、僧帽弁輪をもつ解剖モデル）
- 心腔：解剖は afRemodeled（§9.1）
- 基質：LSPV・RSPV のスリーブの先端を「トリガー」とし、周期 150〜250 ms でランダム発火（シード付き乱数）。心房筋の ERP を 160〜200 ms（斑状のばらつき）に短縮。PV スリーブは 0.5 mm/ms・ERP 180 ms
- **AF の表し方（Phase 4 の決定）**：一般心房筋の波長（1.0 mm/ms × ERP）は LA の周長より長く、複数波の旋回は持続しない。AF は「PV トリガーの高頻度発火による不規則な伝導（fibrillatory conduction）」として表し、トリガーを隔離すると洞調律に戻る（心房・心室とも不規則になることをテストで確認）
- 誘発：トリガー発火で自然に始まる（spontaneous）
- 根治判定：PV ごとに、生きている頂点だけをたどって LA 本体からスリーブに届かないこと（entrance block。`viability = 0` の閉曲線と同じ意味）。加えて各 PV のスリーブ先端を刺激しても LA 本体に伝わらないこと（exit block）。隔離後もトリガーは PV 内で発火し続ける（PV 電位の解離）
- 学習ゴール：環状カテーテルで PV 電位を見る → 隔離線 → exit block 確認
- **AF の型（症例の選択肢 `CaseOptions.afType`、Phase 7 の追補 AF-2・AF-3）**：`pv`（既定・上のとおり）、`pvSvc`（非 PV トリガー）、`persistent`（持続性。PV のトリガーは置かず、天蓋の旋回だけで AF が続く）。チュートリアルは `pv`・`pvSvc`・`persistent`
  - `pvSvc` の基質：SVC の心筋スリーブ（afRemodeled の SVC は RA から先 20 mm）を PV のスリーブと同じ 0.5 mm/ms・ERP 180 ms にし、先端に周期 150〜250 ms のトリガーを加える。PVI の後も AF が続く
  - 根治判定（`pvSvc` で追加）：SVC の entrance block（接合部から 6 mm 以上上のスリーブが、生きている頂点だけをたどって RA 本体から届かない）と exit block（SVC の先端を刺激しても RA 本体に伝わらない）。接合部の 4 mm 上を一周すれば隔離になる（洞結節から約 10 mm 離れる）
  - 注意：洞結節の部位・右横隔神経の走行（模式）から 5 mm 以内の RF で注意を出す（§7）。洞機能不全・横隔神経麻痺は再現しない
  - 学習ゴール（`pvSvc` だけ、`LearningGoal.applies`）：PVI 後も続く AF で環状カテーテルを SVC に置き SVC 電位を記録 → SVC 隔離 → AF の停止
  - `persistent` の基質（`src/core/arrhythmia/persistent.ts`、§4.2）：LA 天蓋の低電位領域に固定した旋回（局所の駆動源）と、周りの細動様伝導。中心の瘢痕の周りの遅い伝導の輪（channel）を、出口 1 か所の線維化の輪が囲む。旋回は症例を作るときに位相の初期化で始める（症例は AF が続いた状態で始まる。複製でも同じように始めるので、病変で旋回の道が断たれていれば再現しない）。PV のトリガーも残る
  - 場所を後壁でなく天蓋にした理由（先生と決定）：このモデルの後壁は PV の間が狭く（PV の口・スリーブから最大 6.8 mm）約 3 × 3 cm の領域が入らない。小さくするとメッシュが粗く旋回が続かない。そのため後壁隔離（box）はこの症例の治療法に含めない
  - 根治判定（`persistent` で追加）：天蓋の旋回が止まる＝ channel を横切る病変（同じ病変の複製で旋回を始め直し、channel が興奮し続けないこと）、または領域の隔離（channel が LA の残りから病変で隔てられる）。PVI だけでは AF が続く
  - 学習ゴール（`persistent` だけ）：ボルテージマップで天蓋の 0.5 mV 未満の点を 5 点以上 → PVI 後も続く AF で旋回を通電で止める → AF の停止。双極の振幅は channel 約 0.3〜0.5 mV、瘢痕も 約 0.2〜0.5 mV（周りの心房の遠隔電位が乗るため 0.1 mV 未満にはならない）、正常 約 2.1〜2.4 mV

### 5.2 通常型心房粗動（CTI 依存性）

- 心腔：RA（三尖弁輪、CTI、CS 口、IVC、SVC、分界稜、Eustachian 稜）。解剖は拡大した RA（aflRemodeled、§9.1）
- 基質（`applyAflSubstrate`）：CTI を 0.3 mm/ms・ERP 230 ms に、RA を 0.6 mm/ms・ERP 180 ms に（§4.2 の Phase 4 の表）。分界稜（SVC の縁 → IVC の縁）と Eustachian 稜（IVC の縁 → CS 口）を、線に沿った向きだけ伝導する完全な機能的ブロック線にし（`TissueState.fiber` / `cvLongitudinal`）、大静脈の管は興奮しない。これで回路の前側が三尖弁輪、後ろ側が「SVC − 分界稜 − IVC − Eustachian 稜」で囲まれる
- 洞調律の既定では分界稜の異方性を設定しない（AFL の基質だけ）
- **調整の経緯**：正常の RA（短径 38 mm）と 1.0 mm/ms では、三尖弁輪の周りの一周が CTI の ERP（230 ms）より短く、旋回が持続しない。RA を拡大し（AFL の患者では右房拡大がよくある）、RA の伝導速度を目標から逆算した
- 誘発：CS 口からのバースト刺激（300 → 200 ms）。CTI は ERP が長いので中隔側 → 側壁側に通れず（一方向性ブロック）、反時計回りの旋回になる。三尖弁輪の縁の興奮の位相が、中隔から His の方向へ増え続けることをテストで確認
- 根治判定：CTI の中で、三尖弁輪から IVC までの病変線が中隔側と側壁側を隔てる（線の完成）。CS 口と低位外側 RA からそれぞれ刺激し、反対側への到達が病変のない同じ基質より 30 ms 以上遅れる（両方向性ブロック）。線は三尖弁輪の縁から IVC の口（IVC の領域。ホバーで「IVC」と出る所）まで引けば完成する。IVC の領域は RA との接合部の輪から始まる（§9.1）ので、口まで引いた線の端に興奮する CTI は残らない。IVC の中へ延ばしてもよい
- 学習ゴール：CS 近位→遠位の順序・ハロー電極で方向確認 → 連続線 → 両方向性ブロック確認
- **時計回り（Phase 7、別の症例 `afl_cti_cw`）**：基質・根治の基準は反時計回りと同じ。低位外側 RA からのバーストで、CTI が側壁側 → 中隔側に通れず、側壁を上行して中隔を下行し、CTI に中隔側から入る時計回りの旋回になる（周期長 約 258 ms）。鑑別：CS はどちらの向きでも近位 → 遠位。反時計回りはハローが H 19-20 → H 1-2（側壁を下行）でその後に CS 口、時計回りは CS 口の後に H 1-2 → H 19-20（側壁を上行）。旋回方向の設問は、誘発された粗動のハローの順序（`flutterDirection`）で正誤を決める

### 5.3 AVNRT（遅伝導路、通常型）

- 心腔：RA（Koch 三角：His 束電位記録部位、CS 口、三尖弁輪中隔側）
- 基質：Koch 三角に速伝導路（前上方の房室結節の頂点を入口、AH 80 ms・ERP 320 ms）と遅伝導路（後下方の遅伝導路部位を入口、AH 200 ms・ERP 200 ms）を置き、両者が共通路（His の手前）で合流する簡易 2 経路モデル。経路は伝導時間・ERP・減衰伝導をもち、速伝導路は共通路から逆行する（§4.2）。入口の頂点が病変になると、その経路は使えない
- 誘発：心房期外刺激（S1 600 ms、S2 を 10 ms 刻みで短縮）。速伝導路 ERP に達すると遅伝導路経由となり AH 間隔がジャンプ（≥ 50 ms）、エコーで頻拍が始まる
- 遅伝導路の領域（QA の追補、先生と決定）：遅伝導路は 1 点ではなく、Koch 三角の後下方（CS 口と三尖弁輪の間）の数 mm の領域。入口は目印から半径 3.5 mm の頂点の集まり（表示の「遅伝導路部位」も同じ半径）。入口の頂点が生きていればその興奮で、焼けていれば領域の生きている頂点のうち最も早く興奮した頂点で遅伝導路に入る。領域の頂点のうち焼けた割合が 60 % 以上で離断（遅伝導路の伝導が消え、jump も出ない）、20〜60 % で修飾（遅伝導路の ERP が 60 ms 延び、遅伝導路を下行した興奮は速伝導路を逆行しない：jump は残るがエコーが出ず非誘発。実臨床でも完全離断より修飾で終わることが多い）、20 % 未満は変わらない。通電中の接合部調律は ABL の先端が領域内のとき
- 根治判定：遅伝導路の領域の 20 % 以上（修飾または離断）が焼けていて、同じプロトコルで非誘発（速伝導路は保たれ、AH は減衰伝導の式どおり）
- 学習ゴール：His 記録 → jump 確認 → 遅伝導路通電 → 接合部調律と非誘発
- 心室刺激（RV）では速伝導路を逆行して求心性に心房が興奮する（VA 伝導、§4.2）。WPW の偏心性の心房興奮と見比べられる

### 5.4 WPW（副伝導路）

- 心腔：LA（既定の左側自由壁）。部位は症例の選択肢 `CaseOptions.apSite` で選ぶ（Phase 7 の追補）：左側自由壁（既定）・右側自由壁・後中隔・前中隔
- 部位の付着部（心房側、各 2 頂点）：左側自由壁＝僧帽弁輪の縁のうち最も側方、右側自由壁＝三尖弁輪の縁のうち最も右、後中隔＝CS 口の中心に最も近い三尖弁輪の縁（右後中隔。左後中隔は扱わない）、前中隔＝His 束の頂点から 3 mm 以上離れた最寄りの三尖弁輪の縁（付着部で通電すると His 近傍の警告 5 mm 以内）。2 頂点は最寄りの頂点とその隣の弁輪の頂点でひとかたまりにする
- 部位ごとの値：心室内伝導（§4.2）・デルタ波の向き（§5.5）・推奨の誘発部位（左側自由壁は CS 遠位、右側自由壁・中隔は HRA）。ERP・伝導時間は共通
- 右側・中隔（と部位を伏せたとき）は、三尖弁輪のマッピングにハロー 20 極を置く（§10）
- 部位を伏せる（`apHidden`）：部位を無作為に選び、名前・推奨の刺激部位を出さない（既定の刺激部位は HRA）。学習ゴールの最初に「体表 ECG のデルタ波の極性から部位を推定する」設問（4 択）が加わる（`LearningGoal.applies` で、伏せたときだけ扱う）
- 基質：部位の 2 頂点に、心房—心室を直結する副伝導路。洞調律では心室側へ早期伝導（デルタ波・短い PR、His 経由の興奮と融合）、心房期外刺激で副伝導路の順行性 ERP に達すると房室結節経由で心室に至り、副伝導路を逆行して順行性 AVRT を開始。RV 刺激では副伝導路を逆行し（房室結節の逆行 VA 約 130 ms より早い）、心房の最早期は付着部（左側自由壁は CS 遠位が早い偏心性、右側自由壁はハローの側方、後中隔は CS 口の近く、前中隔は His の近く）
- 誘発：左側自由壁は **CS 遠位**、右側自由壁・中隔は **HRA** からの心房期外刺激（§5.6 の既定から変更）。S2 で付着部の心房が興奮してから、房室結節 → 心室 → 副伝導路を通って興奮が付着部に戻るまでの時間が、付着部の周りの心房の不応期より短いとエコーが止まる（左側自由壁を HRA から、右側・中隔を CS から刺激すると続かなかった）。心室刺激でも可
- 根治判定：副伝導路の心房側付着部のどれか 1 頂点が `viability = 0`（副伝導路は 1 本の束なので 1 点で途絶える。QA の追補、先生と決定。LAT マップの最早期点を標的にして、病変の半径内に付着部が入れば成功）。デルタ波消失（洞調律で判定）、同プロトコルで非誘発
- 頻拍中の通電：禁止しない。AVRT 中の RF では「頻拍が止まるときにカテーテルがずれやすい」注意を表示する（ずれは再現しない）。チュートリアルの案内は、AFL は粗動中に CTI へ通電（通電中の停止が良い所見）、AVNRT は洞調律で通電（接合部調律が目印、VA ブロックで中止）、WPW は洞調律か心房ペーシング中、AF の PVI は洞調律でも AF 中でも
- 学習ゴール：（部位を伏せたとき）体表 ECG から部位を推定 → 弁輪多極カテーテルで最早期部位 → AV（または VA）融合部位 → 通電後の消失確認。チュートリアルは左側自由壁だけ

### 5.5 心室と体表 ECG の扱い

心室はメッシュを持たせず、刺激伝導系（`src/core/conduction/ConductionSystem.ts`）の 1 コンパートメントで表す。房室結節の経路（入口頂点の心房興奮 → 伝導時間 → 共通路）→ His（ERP 250 ms）→ HV 後に心室（ERP 250 ms）。副伝導路は心房付着部の興奮から心室へ（順行）、心室の興奮から心房付着部へ（逆行）。RV ペーシングは心室を直接興奮させる。心房への出口（逆行伝導）は、エンジンがメッシュの頂点を正確な時刻に興奮させる。体表 ECG は EGM パネルの最上段に出す（`src/core/ecg/SurfaceEcg.ts`）。

- **心房成分（P 波・粗動波・f 波）**：φ モデルの電流源から心房の電気ベクトル p = Σ Iₘ (x − c) を求め、誘導の方向に投影する（Phase 4 で、1 拍ごとのテンプレートから変更。頻拍のように切れ目のない興奮でも破綻しない）。洞調律の P 波幅は normal 約 102 ms（< 120 ms）、I・II は陽性、V1 は前半陽性（約 +0.05 mV）・後半陰性（約 −0.14 mV）の二相性（低域通過フィルタ後。フィルタ前は +0.07／−0.17 mV）。二相性には右心耳と、洞結節を分界稜の上端（後外側）に置くことが必要だった（Phase 4 の追補）。**低域通過フィルタ（QA の追補）**：メッシュ上の離散的な興奮で、心房の電気ベクトルに 2〜8 ms 周期のギザギザ（高周波）が出るため、実機の心電図のフィルタに相当する 1 次の低域通過を 2 段（遮断周波数 40 Hz、仮定値・教育用近似。`ATRIAL_ECG_FILTER_HZ`）かけてから誘導に投影する。波形は約 6〜8 ms 遅れ、振幅は 1〜2 割小さくなる（洞調律の II の P 波の頂点 0.18 → 0.16 mV）。心室成分（QRS・T）は拍ごとのなめらかな式なのでかけない
- **通常型 AFL の粗動波（Phase 7 の追補）**：AFL の症例だけ心房間の連結を変える（§4.2）。LA への入り方が RA の中隔の興奮の順番に従い、反時計回りは LA が下から上へ、時計回りは上から下へ興奮する。陰性の面積 / 陽性の面積は（低域通過フィルタ後）、反時計回りで II 2.44・III 3.66・aVF 3.03（下壁誘導で陰性優位。≧ 1.5 をテストで確認）、時計回りで II 0.60（陽性寄り。< 0.85 をテストで確認）・III 1.71・aVF 0.93。時計回りの III・aVF と、両方向の V1（陰性優位）は臨床の典型と合わない（LIMITATIONS）
- **心室成分（Phase 7 で 12 誘導化）**：心室はメッシュを持たないので、拍の種類ごとに「時刻とともに向きの変わる電気ベクトル」の和（成分ごとにガウス関数の時間経過と 3 次元の向き）で表し、心房成分と同じ誘導の方向に投影する（`SurfaceEcg.ventricularVector`）。成分の向きは Phase 6 までの I・II・V1 のテンプレートの振幅から逆算し、3 誘導の波形はほぼ変わらない（QRS と I・II の T のピークの差 15 % 以内をテストで確認）。QRS の形は「拍の種類ごとの典型的な形」。副伝導路の部位はデルタ波の典型的な極性だけを扱い（下の表）、精密な局在アルゴリズムは再現しない
- **誘導の方向**（仮定値・教育用近似）：肢誘導は I =（1, 0, 0）・II =（0.5, −0.87, 0）から Einthoven の関係で III・aVR・aVL・aVF を作る（III = II − I、aVR + aVL + aVF = 0）。胸部誘導は水平面の方向：V1 =（−0.25, 0, 0.97）、V2 = 前方、V3 = 72°、V4 = 55°、V5 = 30°、V6 ≈ 左方（+x から +z へ測る角度）
- **胸部誘導の近接補正（教育用の経験的補正、Phase 7）**：胸部誘導は心臓に近く、近接電界の影響で電気ベクトルの投影より大きく出るため、誘導ごとに QRS（脱分極：QRS・デルタ波）と T 波（再分極）に別の正の係数を掛ける（`SurfaceEcg.ts` の `PROXIMITY_GAIN` の 1 か所）。正常洞調律で V2〜V4 の R 波が 1〜2 mV 前後（V2 0.8・V3 1.0・V4 1.4 mV）、R 波は V1 から V5 まで漸増し、移行帯（R/S が 1 を超える）は V3〜V4、T 波は V2〜V6 で陽性。係数は正なので極性（デルタ波の向きなど）は変わらない。心房成分（P 波・II の鋸歯状波など）と肢誘導には掛けない。主成分の前後成分も、移行帯が V3〜V4 になるよう前へ寄せた（V1 の S の大きさは係数で保つ）

| 誘導 | V1 | V2 | V3 | V4 | V5 | V6 |
|---|---|---|---|---|---|---|
| QRS の係数 | 1.5 | 4 | 6 | 11 | 3.2 | 1.5 |
| T 波の係数 | 1.5 | 5 | 3 | 3 | 2 | 1.5 |
- **QRS**：中隔（右前方）→ 主成分（左下後方）→ 基部（右上方）。I・II は qRs、V1 は rS、aVR は陰性、胸部誘導は V1 から V6 へ R が大きくなり移行帯は V3〜V5、V5・V6 に中隔性の小さな q
- **T 波**：QRS 開始から QT − 80 ms を頂点とする。I・II・V2〜V6 は陽性、V1 は平坦〜わずかに陰性。T 波がないと臨床的に不自然であり、R on T などを説明できないため加える

## 6. 心内心電図（`src/core/egm`）

**φ モデル（電流源密度近似）**で、単極・双極・遠隔・非接触を 1 つの式で表す（`src/core/egm/EgmGenerator.ts`）。

1. 各頂点の膜電位 Vm を、活性化からの経過時間に対する活動電位テンプレート（§4.2 追加表）で与える
2. メッシュ上の余接（cotangent）ラプラシアンで頂点ごとの膜電流 Iₘ を求める：Iₘ,ᵥ ∝ ½ Σᵤ (cot α + cot β)(Vmᵤ − Vmᵥ) × voltageᵥ / 2.5。波面の前方は湧き出し（＋）、後方は吸い込み（−）で、Σ Iₘ ≈ 0
3. 電極の 3D 位置 x の電位を **φ(x) = K Σ Iₘ,ᵥ / |x − xᵥ|** とする（K は接触・2 mm 双極で正常心房 ≈ 1〜3 mV になるよう較正）

この式から次の性質が自然に出る。

- **単極電位**：起源で QS 型、伝導の途中で RS 型、終点で R 型。最大下降点（intrinsic deflection）が局所の活性化時刻と一致する
- **双極電位**：2 電極の単極差分。電位を頂点ではなく電極座標で計算するため、電極間隔がメッシュの辺長より短くても 0 にならない。波面の向きに対する方向依存性も出る
- **遠隔電位**：Σ Iₘ ≈ 0 のため遠方では双極子として振る舞い、距離の 2 乗程度で減衰する。非接触電極（壁から離れた電極）は鈍く低振幅になる
- **瘢痕・病変**：`viability = 0` の頂点は電流源にならず、そこへ向かう辺も除く（no-flux 境界）。病変の上では局所の双極電位が消え、単極には遠隔成分が残る
- **心室成分**：心室はメッシュを持たないため、心房カテーテルの双極に乗る V の遠隔電位、His の H・V、RV の局所 V はテンプレートで合成する（§4.2 追加表）。His の A は Koch 三角の心房筋から φ モデルで計算する
- **計算量**：電流源は活性化から 16 ms 以内の頂点とその隣接（波面付近）に限る。膜電位もその候補と隣接の分だけ求め、全頂点を見るのは活性化時刻の比較 1 回だけにする（AF-1。候補は頂点番号の順に並べ、和の順序を変えないので結果は高速化の前と同じ。参照の実装との一致をテストで確認）。心房の再分極（Ta 波）は省く。開発機の Node で 1 秒ぶんの計算は AF 約 0.17 秒（高速化の前は 0.35 秒）、他の症例 約 0.05〜0.06 秒（同 0.15〜0.2 秒）。画面では、計算が追いつかないときに実時間の何倍で動いているかを出す
- **部位特性**：PV 電位（鋭い高周波成分、心房電位との二峰）、遅伝導路（分裂電位）、AF（fractionation、頂点の不規則な活性化の自然な帰結）

### 6.1 マップ（Phase 3、`src/core/mapping`）

実機と同じく、**カテーテルで取得した点からの補間**でマップを作る。点が少ない場所は粗く、増えるほど正確になる。

- **点の取得**：置かれているマッピングカテーテル（環状・多極・ABL）の、両電極が接触している双極ごとに 1 点。手動の「取得」と、多極カテーテルの 1 拍ごとの自動取得（既存の点から 1.5 mm 以内は取り直さない）。注釈には電極の単極電位の差を使う（心室の遠隔電位の合成成分は含まない）
- **基準の拍**：基準チャンネル（既定 CS 9-10）の興奮は、振幅ではなく傾き |dV/dt| の局所最大で取る。CS には心室の遠隔電位（鈍く大きい）が乗るため、振幅で取ると V を拾ってしまう。WOI の後端まで記録し終えた最新の拍を使う。ただし、そのカテーテルを最後に動かした時刻（どれかの電極が前の位置から 2 mm 以上動いた時刻、`engine.settledSince`・`MAP_DEFAULTS.moveResetMm`）より後に WOI が始まる拍に限る。まだなければ「動かした後の拍を待っています」（`AcquireResult.reason = 'settling'`）。動かす前の拍を使うと、前の位置の電位が新しい位置の点になった（QA の所見 19）
- **LAT**：基準からの時間。既定は双極の最大振幅の時刻、選択肢として単極の −dV/dt 最大の時刻。セルオートマトンの活性化時刻との差は ±5 ms 以内（立ち上がりの中ほどで電流が最大になるため、約 +3 ms ずれる）
- **電位**：双極（または方向非依存）の WOI 内の peak-to-peak
- **WOI の規則**：既定は基準から −150〜+100 ms。**頻拍中（調律が tachycardia）は、WOI の幅が周期長を超えると同じ点に 2 拍分の興奮が入り LAT が破綻する**ため、手動設定でなければ幅を「周期長 − 10 ms」にし、基準から −10 ms を中心に置く：WOI = [−(CL − 10)/2 − 10, +(CL − 10)/2 − 10]（例：CL 250 ms → −130〜+110 ms）。周期長は基準の拍間隔の中央値。ユーザーが WOI を動かすと手動設定になり、自動切り替えはしない（「既定（自動）に戻す」で解除）
- **補間**：取得点から各頂点への表面距離（メッシュの辺をたどるダイクストラ法。心房間の連結は通らない）が到達距離以内の点を、重み 1/(d² + 1) で平均する。到達距離より遠い頂点は「データなし」
- **方向非依存 EGM**（`theme.features.omnipolarEgm`、グリッド型）：隣り合う 3 電極から直交する 2 本の双極 b1・b2 を作り、b(θ) = b1 cos θ + b2 sin θ の peak-to-peak が最大になる θ の信号で電位と LAT を取る。**通常の双極では、波面と電極の並びが直交する場所や波面の衝突部位で見かけの低電位（< 0.5 mV）が出るが、方向非依存 EGM では出ない**（テストで確認）。実機のアルゴリズムとは無関係の教育用近似
- **表示**：LAT マップ（最早 → 最遅を `activationRamp` の先頭 → 末尾）、ボルテージマップ（瘢痕閾値未満は `scar`、正常閾値以上は `voltageRamp` の末尾）、伝播アニメーション（LAT マップを繰り返し再生し、波面を `wavefront` 色で）。カラーバー、取得点の印（形と大きさは `theme.pointMarker`）。テーマを切り替えても取得点は残り、同じ点から同じ LAT・電位が出る（違うのは色と用語だけ）
- **表示**：Canvas 2D でスクロール描画。スイープ速度 25／50／100／200 mm/s、ゲイン可変、フリーズしてキャリパー計測（AH・HV・サイクル長）。フリーズ中もシミュレーションは進む。チャンネル順は体表 ECG → HRA → HIS d/p → CS 9-10 … 1-2 → 環状（CIRC）／多極（MS・GRID）→ ABL d/p → RV。置かれていないカテーテルと、テーマで使えないカテーテルのチャンネルは表示しない。行が多いときは縦スクロール
- **Phase 1 の仮実装の解消（Phase 2）**：両心房を 1 つのシミュレーションで動かすため、HRA は常に RA 上にあり、His の A はメッシュから計算する。カテーテルは 3D 上で配置する（§10）

## 7. アブレーション（`src/core/ablation`）

**通電の時計**：病変の成長だけを 1×／5×／10×（既定 5×）で進め、EGM・伝播・体表 ECG は実時間のまま（通電中も電位の変化が見える）。通電時間はシミュレーション時間で表示し、計算が重い症例では実効の倍速（例：「5× 設定・実効 3.5×」）を並べて表示する。

## 8. マッピングシステムの切り替え（`src/systems`）

### 8.1 方針

- CARTO®（Biosense Webster / J&J MedTech）、EnSite™（Abbott）、OPAL HDx™（Boston Scientific）は各社の商標。本アプリは非公式・教育目的で、各社と無関係。

## 9. ジオメトリー作成

### 9.1 プリセットモード

**方針：まずパラメトリック自作、後で公開 3D モデルへ差し替え可能にする。**

- `src/core/geometry/parametric/` で、符号付き距離関数（楕円体・楕円断面の管のなめらかな和）を Surface Nets で三角形メッシュにする（格子 2 mm、辺長の中央値 約 2 mm、頂点 normal 約 5,000・afRemodeled 約 5,900）。緯度経度メッシュと違い、極や継ぎ目ができない
  - LA：楕円体＋PV 4 本（上下径を長軸とする楕円断面の管、口から 15 mm）＋LAA＋僧帽弁輪の開口
  - RA：楕円体＋SVC・IVC＋右心耳＋三尖弁輪の開口＋CS 口
  - 弁輪・静脈の端・CS 口は平面で切り抜いた穴とする
  - IVC の領域は RA との接合部の輪（軸方向に管の長さ ± 1.5 mm、軸から半径の 1.6 倍以内。CTI の「IVC 口」の目印を選ぶ輪と同じ）から外側（全寸法セット、仮定値）。管と楕円体のなめらかな和で口が漏斗状に広がり、以前は管の先端から測っていたため口のまわりに約 5 mm の幅で CTI が残り、口まで引いた CTI の線の端を粗動が回り込んだ（QA の追補で修正）
- 頂点ごとの領域ラベル（`src/core/geometry/regions.ts`、31 種。Phase 4 で Bachmann 束の帯と Eustachian 稜、Phase 4 の追補で右心耳を追加）を生成時に付ける。分界稜は SVC の縁から IVC の縁まで、Eustachian 稜は IVC の縁から CS 口まで、RA 表面の線として定義する：LA 本体・中隔・天蓋・後壁・前壁、LAA、僧帽弁輪、PV 4 本のスリーブと口、RA 本体・中隔、卵円窩、洞結節、分界稜、CTI、CS 口、His 束部位、房室結節、遅伝導路部位、三尖弁輪、SVC、IVC。PV のスリーブと口は、軸からの距離を PV の半径で割った値が最も小さい PV に割り当てる（Phase 5：近接する右 PV の管の壁を隣の PV に割り当てないため）
- LA と RA は 1 つのメッシュにまとめ、Bachmann 束・卵円窩縁・CS 筋束の 3 か所を心房間の連結でつなぐ。洞調律で LA に最初に入るのは卵円窩縁（洞結節を分界稜の上端に置いたため。連結はどれも一般心房筋と同じ伝導速度）
- 洞結節は分界稜の上端（SVC と RA の接合部の後外側、方向 (−0.6, 0.75, −0.15)。仮定値）
- 寸法は `src/core/geometry/parametric/dimensions.ts` に集約し、**normal**（AVNRT・WPW）、**afRemodeled**（AF）、**aflRemodeled**（AFL：RA と三尖弁輪を normal の 1.2 倍。RA の中心は短径から決め、LA と食い込まないようにする）の 3 セットをもつ。構造物の向き（PV・弁輪・CS 口などの方向）は `atria.ts` の `ORIENT` にまとめた仮定値（教育用近似）
- メッシュの読み込み口は `ChamberLoader` インターフェース（`src/core/geometry/ChamberLoader.ts`）に統一する。公開モデルを使う場合はライセンス（CC BY など）を `docs/ASSETS.md` に記録する。カテーテル配置などの幾何計算はメッシュだけで行い（`MeshQuery`）、SDF に依存しない
- **glTF ローダ（Phase 7、`src/core/geometry/gltf`）**：glTF（GLB、または data URI を埋め込んだ .gltf）の三角形メッシュと、領域ラベルの JSON（`LabelFile`：頂点 index → 領域名。index は glTF の POSITION を文書の順につないだ通し番号）から `BiatrialModel` を作る（`loadGltfModel`・`gltfChamberLoader`）
  - 手順：プリミティブをつなぐ → 単位（メートルなら mm へ。差し渡し 2 未満をメートルと判定、JSON の `unit` で指定可）→ 同じ位置の頂点を溶接 → LA と RA に分ける（JSON の `chambers` → メッシュ名 LA／RA → 開口の数 5／4 → 左右）→ 領域 → 目印・開口・PV・連結を求める（`derive.ts`）
  - 領域：JSON で全頂点を与えればそのまま。一部だけ（例：左心耳）なら、形からの**半自動推定**（`estimate.ts`）を JSON で上書きする。推定は座標系がアプリと同じ（+x = 左、+y = 頭側、+z = 前方）であることを前提に、開口（境界の輪。円を当てはめて中心と軸）から僧帽弁輪（LA の最大の輪）・PV（左右・上下）・三尖弁輪（RA の最大）・CS 口（最小）・SVC／IVC（上下）を決め、管の付け根は輪からメッシュの辺で管の壁をたどって求める。Koch 三角・洞結節・分界稜・Eustachian 稜・CTI・卵円窩はパラメトリック形状と同じ規則。左心耳・右心耳・Bachmann 束は推定しない
  - 目印：JSON の `anchors` > 推定の途中で決めた目印 > 領域ラベルの重心。分界稜・Eustachian 稜の線と心房間の連結も JSON（`lines`・`bridges`）で与えられる
  - 書き出し：`exportModelToGltf`（GLB は LA・RA の 2 メッシュ、メートル。ラベル JSON は領域・目印・線・連結を含む）。`npm run export-gltf -- normal 出力.glb 出力.labels.json` で Blender での手直しの出発点を作れる
  - 動作確認：パラメトリックモデルを glTF に書き出して読み戻す往復テスト。頂点・三角形・領域・目印・連結が一致し、4 症例が誘発 → 標準の通電で根治する。ラベルなし（推定）でも AFL が誘発・根治する。three.js の GLTFLoader でも開けることを確認した
  - 実際の公開モデルの選定は別途行う（`docs/ASSETS.md`）

### 9.2 収集モード（FAM 風）
- プリセットのメッシュを「真の解剖」として隠し持ち、マッピングに使う自由配置のカテーテル（ABL・環状・多極）の電極の位置を記録する（間隔 1.5 mm 以上）。CS・His・HRA・ハローは使わない
- 壁から 3 mm 以内の電極が、まわり 5 mm の頂点を「収集済み」にする（仮定値・教育用近似）。表示するのは 3 頂点とも収集済みの三角形だけで、**未収集の部分は穴になる**（点が足りない場所は形が分からないことを体感させる。Phase 6 の決定：凸包・楕円体からの変形は使わない）
- 真のメッシュは見えない当たり判定として残し、未収集の場所へもカテーテルを動かせる。「真の解剖を重ねる（答え合わせ）」で線として重ねて表示できる
- 内部の電気生理計算は常に真のメッシュ上で行う。表示メッシュは真のメッシュと同じ頂点なので、マップ・病変はそのまま重なる（「マップが粗くても電気生理は正しい」）
- 被覆率（心房ごとの収集済みの頂点の割合）を表示する

配置の方式（`src/core/catheter/placement.ts`）：

- **経路に沿って動かす**：CS・His・HRA。経路（`guidedPaths.ts`）は CS＝RA 内の CS 口の手前 → CS 口 → 僧帽弁輪の後方に沿って側壁へ（心外膜側）、His＝三尖弁輪の縁を His 部位から後下方へ（遠位電極を弁輪に置き、近位電極は心房中隔側へ並べる）、HRA＝洞結節から RA 側壁を下る経路
- **自由ドラッグ**：ABL・環状・多極。3D 上の点（raycast）に置く
- 操作：カテーテルを一覧で選ぶ → 3D 上でクリック／ドラッグ（経路カテーテルは経路上の最寄り位置へ）。ホイールで押し込み／引き戻し、Shift＋ホイールで回転。操作パネルのスライダーでも同じ操作ができる。選択を解除すると視点を回せる

- 刺激部位（Phase 6 で追加）：環状（1-2）・ハロー遠位（1-2）。電極が壁に接触していなければ捕捉しない（刺激アーチファクトだけ）。PVI の exit block は環状カテーテルからの刺激を標準とする（ABL からの刺激も選べる）

## 13. 検証

- `src/core` は vitest で単体テスト（伝播が全頂点に届く、病変が遮断する、各シナリオで誘発→根治が成立する、など）
- 画面の操作の流れは Playwright の E2E（`e2e/`、`npm run e2e`：本番と同じビルドを `vite preview` で開き Chromium で操作する。WebGL はソフトウェア描画）。起動・症例と選択肢・テーマ・体表 ECG の誘導数・マップ・刺激・通電と注意・クライオ／PFA・浮腫と再伝導・アデノシンによる頻拍の停止・根治判定・URL・研究用 JSON・収集モード・チュートリアル 9 本を確かめる（22 本。ファイルの中でも並行に流し、手元 4・CI 3 の並列で約 3 分）。CI は `.github/workflows/e2e.yml`（main への push と手動。Pages の公開とは別で、失敗しても公開は止めない）
- E2E 用の口：URL に `?e2e=1` を付けたときだけ `window.__ep`（`src/state/e2eHooks.ts`）を出す。3D 上のカテーテル操作（解剖の目印・頂点・PV の中に置く）、時間の早送り（刺激プロトコル・ゴール・調律の表示も進める）、多数点の RF 通電、状態の読み取りだけを提供し、画面のボタン・選択・表示は本物の操作で確かめる。画面の URL の同期では `e2e` は残らない
- チュートリアルを人が通して操作した確認と、E2E で見つかった不具合は `docs/QA_LOG.md` に記録する
- 電気生理の妥当性は不整脈専門医・経験豊富なメディカルスタッフのレビューで確認し、`docs/REVIEW_LOG.md` に記録する
- ビルドはライブラリごとに分ける（`vite.config.ts` の `manualChunks`：three・react-three・react とアプリ本体。公開し直してもライブラリ分はキャッシュに残る）。「このシミュレータについて」の全文は開いたときに読み込む
- 既知の単純化と限界は `docs/LIMITATIONS.md` に列挙し、アプリ内「このシミュレータについて」（操作パネルの見出しの下）で表示する。LIMITATIONS.md はビルド時にそのまま取り込むので、文書を直せば画面も揃う
