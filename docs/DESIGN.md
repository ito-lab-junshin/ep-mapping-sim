# EP Mapping Simulator 設計書

不整脈アブレーションの 3D マッピング教育シミュレータ。ブラウザだけで動き、GitHub Pages で公開する。

- 対象ユーザー：臨床工学技士の学生、若手メディカルスタッフ（将来は研究用途へ拡張）
- 開発主体：伊藤朋晃（純真学園大学）
- 実装：React + Vite + TypeScript + Three.js（react-three-fiber）+ zustand
- 本書は「何を・なぜ・どこまで」を決める文書。実装の手順は `CLAUDE.md` を参照。

---

## 1. 目的と到達目標

学生が、実機に触れる前に次の流れを一通り体験できること。

1. 不整脈の種類を選ぶ
2. 心腔のジオメトリーを作る（収集モード／プリセット）
3. カテーテルを置き、心内心電図（EGM）が位置に応じて変わることを確認する
4. 頻拍を誘発し、活性化（LAT）マップで機序を読む
5. エネルギーを選んで通電し、ブロック／隔離／非誘発を確認する
6. 同じ症例を CARTO 風・EnSite 風・OPAL HDx 風の画面で見比べ、画面が違っても電気生理は同じだと理解する

**非目標（v1 では作らない）**：透視画像、心室性不整脈、合併症（タンポナーデ・横隔神経麻痺など）、実機と同じアルゴリズムの再現、臨床判断の代替。

## 2. 全体アーキテクチャ

```
┌───────────────────────────────────────────────────────────────┐
│ UI 層（React）                                                 │
│  ControlPanel / EgmPanel / CatheterTray / AblationConsole      │
│  → テーマ・用語・機能フラグは src/systems から受け取る           │
├───────────────────────────────────────────────────────────────┤
│ 3D 層（react-three-fiber）                                     │
│  Scene / ChamberMesh / CatheterModel / LesionMarkers           │
│  → マウス操作（raycast）でカテーテル配置・ポイント収集            │
├───────────────────────────────────────────────────────────────┤
│ 状態（zustand）src/state                                        │
│  選択中システム・不整脈・エネルギー・カテーテル・病変・調律状態   │
├───────────────────────────────────────────────────────────────┤
│ コア（純 TypeScript・UI 非依存・単体テスト可）src/core           │
│  geometry   : メッシュ生成・隣接リスト・領域ラベル               │
│  propagation: セルオートマトン（興奮伝播）                      │
│  egm        : 電極位置 → EGM 波形                               │
│  arrhythmia : 不整脈シナリオ（基質・誘発・根治判定）             │
│  ablation   : エネルギー別の病変モデル                          │
└───────────────────────────────────────────────────────────────┘
```

設計原則：

- **コアは UI を知らない。** `src/core` は Three.js にも React にも依存しない。研究用途で Node.js からバッチ実行できるようにするため。
- **システムの違いは「設定」で表す。** 3 システムの差は `src/systems/index.ts` のテーマオブジェクト（配色・用語・機能フラグ）に閉じ込める。UI コンポーネントが `if (system === 'carto')` と書くのは禁止。
- **ハイブリッド構成。** 伝播と EGM は物理寄り（セルオートマトン）、頻拍の「誘発できたか」「根治したか」はシナリオごとのルールで判定する。見た目の説得力と判定の確実さを両立するため。

| `ConductionSystem` / `VentricularBeat` | 刺激伝導系（`src/core/conduction`）：房室結節の経路（入口頂点・伝導時間・ERP・減衰伝導・逆行）、His、心室の 1 コンパートメント、副伝導路。心室の拍は興奮の由来（`his`／`ap`／`pace`）と、早期興奮のときの His 経由の到達時刻をもつ |
| `Stimulus` / `ProtocolConfig` / `TrainResult` | 刺激（時刻と対象：心房の頂点または心室）、刺激プロトコルの設定（§5.6）、列ごとの結果（捕捉・AH・エコー・誘発）（`src/core/pacing`） |

| `MapType` | 3D ビューの表示モード（`live`：実時間の伝播／`lat`／`voltage`／`propagation`：LAT マップの再生／`regions`） |
| `LatMethod` | LAT の取り方（`bipolarPeak`：双極の最大振幅／`unipolarDvdt`：単極の −dV/dt 最大） |
| `MapSettings` | マップの設定：WOI（`woiBeforeMs`・`woiAfterMs`・手動設定か `woiManual`）、基準チャンネル、LAT の取り方、補間の到達距離 `fillThresholdMm`、ボルテージ閾値 `voltageScarMv`・`voltageNormalMv` |
| `MapPoint` | 取得点：表面上の位置と最寄り頂点、基準からの LAT（判定不能なら null）、電位 mV、カテーテル、信号の種類（`bipolar`／`omnipolar`）、基準時刻 |

単位は **mm と ms** に統一する。

## 4. 興奮伝播モデル（`src/core/propagation`）

### 4.1 セルオートマトン

- 各頂点は 静止(0) → 興奮・絶対不応(1) → 相対不応(2) → 静止(0)。
- 興奮した頂点は隣接頂点へ `距離 / 伝導速度` の遅延で到達予定時刻を書き込む。
- 到達予定はイベントとして時刻順に処理し、刻み幅の途中の正確な時刻で興奮させる。あわせて、辺を共有する三角形の第 3 頂点がすでに興奮していれば、その辺上から直進する経路も候補にする（三角形更新。eikonal 方程式の fast marching 法と同じ考え方）。これにより、到達時刻 × 伝導速度と表面距離の差は 5 % 以内になる（Phase 2 までは刻み幅への丸めと辺に沿ったジグザグ経路のため、実効の伝導速度が設定値より 18〜40 % 遅かった）
- 異方性：両端の頂点が線維方向と長軸方向の伝導速度をもつ辺は、楕円則 1/cv² = cos²θ/cvL² + sin²θ/cvT² で伝導速度を決める（θ = 辺と線維のなす角、cvT = 横方向 = `conductionVelocity`）
- 心房間の連結（`SurfaceMesh.bridges`）は連結ごとの伝導速度 `cvMmPerMs` で伝える
- `viability = 0` の頂点は興奮せず、伝播を遮断する（病変・解剖学的障壁）。
- 刻み幅 2 ms。実時間 1 秒 ＝ シミュレーション 1 秒を基本とし、スロー再生も用意する。

## 5. 不整脈シナリオ（`src/core/arrhythmia`）

各シナリオは基質（`setupSubstrate`）、推奨の誘発法（`induction`）、構造的な根治の基準（`structuralChecks`）と学習ゴールをもつ。誘発と「同じプロトコルで非誘発」は `common.ts` の `tryInduce` / `verifyCure` で、複製したエンジンに刺激プロトコルを走らせて判定する。テスト（`src/core/arrhythmia/scenarios.test.ts`）で 4 症例すべての誘発 → 治療 → 非誘発を確認している。

### 5.1 心房細動（AF）— PVI

- 心腔：LA（4 本の PV 口、LAA、僧帽弁輪をもつ解剖モデル）
- 心腔：解剖は afRemodeled（§9.1）
- 基質：LSPV・RSPV のスリーブの先端を「トリガー」とし、周期 150〜250 ms でランダム発火（シード付き乱数）。心房筋の ERP を 160〜200 ms（斑状のばらつき）に短縮。PV スリーブは 0.5 mm/ms・ERP 180 ms
- **AF の表し方（Phase 4 の決定）**：一般心房筋の波長（1.0 mm/ms × ERP）は LA の周長より長く、複数波の旋回は持続しない。AF は「PV トリガーの高頻度発火による不規則な伝導（fibrillatory conduction）」として表し、トリガーを隔離すると洞調律に戻る（心房・心室とも不規則になることをテストで確認）
- 誘発：トリガー発火で自然に始まる（spontaneous）
- 根治判定：PV ごとに、生きている頂点だけをたどって LA 本体からスリーブに届かないこと（entrance block。`viability = 0` の閉曲線と同じ意味）。加えて各 PV のスリーブ先端を刺激しても LA 本体に伝わらないこと（exit block）。隔離後もトリガーは PV 内で発火し続ける（PV 電位の解離）
- 学習ゴール：環状カテーテルで PV 電位を見る → 隔離線 → exit block 確認

### 5.2 通常型心房粗動（CTI 依存性）

- 心腔：RA（三尖弁輪、CTI、CS 口、IVC、SVC、分界稜、Eustachian 稜）。解剖は拡大した RA（aflRemodeled、§9.1）
- 基質（`applyAflSubstrate`）：CTI を 0.3 mm/ms・ERP 230 ms に、RA を 0.6 mm/ms・ERP 180 ms に（§4.2 の Phase 4 の表）。分界稜（SVC の縁 → IVC の縁）と Eustachian 稜（IVC の縁 → CS 口）を、線に沿った向きだけ伝導する完全な機能的ブロック線にし（`TissueState.fiber` / `cvLongitudinal`）、大静脈の管は興奮しない。これで回路の前側が三尖弁輪、後ろ側が「SVC − 分界稜 − IVC − Eustachian 稜」で囲まれる
- 洞調律の既定では分界稜の異方性を設定しない（AFL の基質だけ）
- **調整の経緯**：正常の RA（短径 38 mm）と 1.0 mm/ms では、三尖弁輪の周りの一周が CTI の ERP（230 ms）より短く、旋回が持続しない。RA を拡大し（AFL の患者では右房拡大がよくある）、RA の伝導速度を目標から逆算した
- 誘発：CS 口からのバースト刺激（300 → 200 ms）。CTI は ERP が長いので中隔側 → 側壁側に通れず（一方向性ブロック）、反時計回りの旋回になる。三尖弁輪の縁の興奮の位相が、中隔から His の方向へ増え続けることをテストで確認
- 根治判定：CTI の中で、三尖弁輪から IVC までの病変線が中隔側と側壁側を隔てる（線の完成）。CS 口と低位外側 RA からそれぞれ刺激し、反対側への到達が病変のない同じ基質より 30 ms 以上遅れる（両方向性ブロック）。線は IVC の中まで延ばさないと、IVC の口のまわりに隙間が残る（実際の手技と同じ）
- 学習ゴール：CS 近位→遠位の順序・ハロー電極で方向確認 → 連続線 → 両方向性ブロック確認

### 5.3 AVNRT（遅伝導路、通常型）

- 心腔：RA（Koch 三角：His 束電位記録部位、CS 口、三尖弁輪中隔側）
- 基質：Koch 三角に速伝導路（前上方の房室結節の頂点を入口、AH 80 ms・ERP 320 ms）と遅伝導路（後下方の遅伝導路部位を入口、AH 200 ms・ERP 200 ms）を置き、両者が共通路（His の手前）で合流する簡易 2 経路モデル。経路は伝導時間・ERP・減衰伝導をもち、速伝導路は共通路から逆行する（§4.2）。入口の頂点が病変になると、その経路は使えない
- 誘発：心房期外刺激（S1 600 ms、S2 を 10 ms 刻みで短縮）。速伝導路 ERP に達すると遅伝導路経由となり AH 間隔がジャンプ（≥ 50 ms）、エコーで頻拍が始まる
- 根治判定：遅伝導路の頂点に病変があり、同じプロトコルで非誘発（速伝導路は保たれ、AH は減衰伝導の式どおり）。通電中の接合部調律（周期 500〜700 ms）は Phase 5（通電の実装）で出す
- 学習ゴール：His 記録 → jump 確認 → 遅伝導路通電 → 接合部調律と非誘発

### 5.4 WPW（副伝導路）

- 心腔：LA（左側副伝導路、既定は左側自由壁。右側・中隔はオプション）
- 基質：僧帽弁輪の縁のうち最も側方の 2 頂点に、心房—心室を直結する副伝導路。洞調律では心室側へ早期伝導（デルタ波・短い PR、His 経由の興奮と融合）、心房期外刺激で副伝導路の順行性 ERP に達すると房室結節経由で心室に至り、副伝導路を逆行して順行性 AVRT を開始。RV 刺激では副伝導路を逆行し、心房は偏心性に興奮する（CS 遠位が早い）
- 誘発：**CS 遠位**からの心房期外刺激（§5.6 の既定から変更）。HRA からの S2 では、房室結節を下行して副伝導路を逆行した興奮が LA 側方に戻ったとき、そこがまだ S2 の不応期にあり、エコーが止まる。心室刺激でも可
- 根治判定：副伝導路頂点が `viability = 0`。デルタ波消失、同プロトコルで非誘発
- 学習ゴール：弁輪多極カテーテルで最早期部位 → AV（または VA）融合部位 → 通電後の消失確認

### 5.5 心室と体表 ECG の扱い

心室はメッシュを持たせず、刺激伝導系（`src/core/conduction/ConductionSystem.ts`）の 1 コンパートメントで表す。房室結節の経路（入口頂点の心房興奮 → 伝導時間 → 共通路）→ His（ERP 250 ms）→ HV 後に心室（ERP 250 ms）。副伝導路は心房付着部の興奮から心室へ（順行）、心室の興奮から心房付着部へ（逆行）。RV ペーシングは心室を直接興奮させる。心房への出口（逆行伝導）は、エンジンがメッシュの頂点を正確な時刻に興奮させる。体表 ECG は EGM パネルの最上段に出す（`src/core/ecg/SurfaceEcg.ts`）。

- **心房成分（P 波・粗動波・f 波）**：φ モデルの電流源から心房の電気ベクトル p = Σ Iₘ (x − c) を求め、誘導の方向に投影する（Phase 4 で、1 拍ごとのテンプレートから変更。頻拍のように切れ目のない興奮でも破綻しない）。洞調律の P 波幅は normal 約 102 ms（< 120 ms）、I・II は陽性、V1 は前半陽性（約 +0.07 mV）・後半陰性（約 −0.17 mV）の二相性。二相性には右心耳と、洞結節を分界稜の上端（後外側）に置くことが必要だった（Phase 4 の追補）
- **QRS**：QRS 開始（V）からのガウス成分の和。I・II は qRs、V1 は rS
- **T 波**：QRS 開始から QT − 80 ms を頂点とする。I・II は陽性、V1 は平坦〜わずかに陰性。T 波がないと臨床的に不自然であり、R on T などを説明できないため加える
- **デルタ波**：副伝導路から先に興奮した拍で、His 経由の興奮が届くまでの時間（融合の程度）だけ緩やかに立ち上がり、その後に His 経由の QRS が続く。左側自由壁の副伝導路として I で陰性・V1 で陽性（A 型）
- **RV ペーシングの QRS**：幅の広い左脚ブロック型・上方軸のテンプレート

**誘導数はユーザーが選択できる**（操作パネルの「体表 ECG」）。

| 選択肢 | 内容 | 実装 Phase |
|---|---|---|
| 1 誘導 | II のみ | 1 |
| 3 誘導（既定） | I・II・V1。AFL の鋸歯状波（II）、WPW のデルタ波極性（I・V1）を教えるため | 1 |
| 12 誘導 | 心室 1 コンパートメントでは局在の根拠が薄いため、心室の簡易ベクトルモデル導入後に実装。それまでは選択肢に「準備中」と表示 | 7 |

## 6. 心内心電図（`src/core/egm`）

**φ モデル（電流源密度近似）**で、単極・双極・遠隔・非接触を 1 つの式で表す（`src/core/egm/EgmGenerator.ts`）。

1. 各頂点の膜電位 Vm を、活性化からの経過時間に対する活動電位テンプレート（§4.2 追加表）で与える
2. メッシュ上の余接（cotangent）ラプラシアンで頂点ごとの膜電流 Iₘ を求める：Iₘ,ᵥ ∝ ½ Σᵤ (cot α + cot β)(Vmᵤ − Vmᵥ) × voltageᵥ / 2.5。波面の前方は湧き出し（＋）、後方は吸い込み（−）で、Σ Iₘ ≈ 0
3. 電極の 3D 位置 x の電位を **φ(x) = K Σ Iₘ,ᵥ / |x − xᵥ|** とする（K は接触・2 mm 双極で正常心房 ≈ 1〜3 mV になるよう較正）

この式から次の性質が自然に出る。

- **単極電位**：起源で QS 型、伝導の途中で RS 型、終点で R 型。最大下降点（intrinsic deflection）が局所の活性化時刻と一致する
- **双極電位**：2 電極の単極差分。電位を頂点ではなく電極座標で計算するため、電極間隔がメッシュの辺長より短くても 0 にならない。波面の向きに対する方向依存性も出る
- **遠隔電位**：Σ Iₘ ≈ 0 のため遠方では双極子として振る舞い、距離の 2 乗程度で減衰する。非接触電極（壁から離れた電極）は鈍く低振幅になる
- **瘢痕・病変**：`viability = 0` の頂点は電流源にならず、そこへ向かう辺も除く（no-flux 境界）。病変の上では局所の双極電位が消え、単極には遠隔成分が残る
- **心室成分**：心室はメッシュを持たないため、心房カテーテルの双極に乗る V の遠隔電位、His の H・V、RV の局所 V はテンプレートで合成する（§4.2 追加表）。His の A は Koch 三角の心房筋から φ モデルで計算する
- **計算量**：電流源は活性化から 16 ms 以内の頂点とその隣接（波面付近）に限る。心房の再分極（Ta 波）は省く
- **部位特性**：PV 電位（鋭い高周波成分、心房電位との二峰）、遅伝導路（分裂電位）、AF（fractionation、頂点の不規則な活性化の自然な帰結）

### 6.1 マップ（Phase 3、`src/core/mapping`）

実機と同じく、**カテーテルで取得した点からの補間**でマップを作る。点が少ない場所は粗く、増えるほど正確になる。

- **点の取得**：置かれているマッピングカテーテル（環状・多極・ABL）の、両電極が接触している双極ごとに 1 点。手動の「取得」と、多極カテーテルの 1 拍ごとの自動取得（既存の点から 1.5 mm 以内は取り直さない）。注釈には電極の単極電位の差を使う（心室の遠隔電位の合成成分は含まない）
- **基準の拍**：基準チャンネル（既定 CS 9-10）の興奮は、振幅ではなく傾き |dV/dt| の局所最大で取る。CS には心室の遠隔電位（鈍く大きい）が乗るため、振幅で取ると V を拾ってしまう。WOI の後端まで記録し終えた最新の拍を使う
- **LAT**：基準からの時間。既定は双極の最大振幅の時刻、選択肢として単極の −dV/dt 最大の時刻。セルオートマトンの活性化時刻との差は ±5 ms 以内（立ち上がりの中ほどで電流が最大になるため、約 +3 ms ずれる）
- **電位**：双極（または方向非依存）の WOI 内の peak-to-peak
- **WOI の規則**：既定は基準から −150〜+100 ms。**頻拍中（調律が tachycardia）は、WOI の幅が周期長を超えると同じ点に 2 拍分の興奮が入り LAT が破綻する**ため、手動設定でなければ幅を「周期長 − 10 ms」にし、基準から −10 ms を中心に置く：WOI = [−(CL − 10)/2 − 10, +(CL − 10)/2 − 10]（例：CL 250 ms → −130〜+110 ms）。周期長は基準の拍間隔の中央値。ユーザーが WOI を動かすと手動設定になり、自動切り替えはしない（「既定（自動）に戻す」で解除）
- **補間**：取得点から各頂点への表面距離（メッシュの辺をたどるダイクストラ法。心房間の連結は通らない）が到達距離以内の点を、重み 1/(d² + 1) で平均する。到達距離より遠い頂点は「データなし」
- **方向非依存 EGM**（`theme.features.omnipolarEgm`、グリッド型）：隣り合う 3 電極から直交する 2 本の双極 b1・b2 を作り、b(θ) = b1 cos θ + b2 sin θ の peak-to-peak が最大になる θ の信号で電位と LAT を取る。**通常の双極では、波面と電極の並びが直交する場所や波面の衝突部位で見かけの低電位（< 0.5 mV）が出るが、方向非依存 EGM では出ない**（テストで確認）。実機のアルゴリズムとは無関係の教育用近似
- **表示**：LAT マップ（最早 → 最遅を `activationRamp` の先頭 → 末尾）、ボルテージマップ（瘢痕閾値未満は `scar`、正常閾値以上は `voltageRamp` の末尾）、伝播アニメーション（LAT マップを繰り返し再生し、波面を `wavefront` 色で）。カラーバー、取得点の印（形と大きさは `theme.pointMarker`）。テーマを切り替えても取得点は残り、同じ点から同じ LAT・電位が出る（違うのは色と用語だけ）
- **表示**：Canvas 2D でスクロール描画。スイープ速度 25／50／100／200 mm/s、ゲイン可変、フリーズしてキャリパー計測（AH・HV・サイクル長）。フリーズ中もシミュレーションは進む。チャンネル順は体表 ECG → HRA → HIS d/p → CS 9-10 … 1-2 → 環状（CIRC）／多極（MS・GRID）→ ABL d/p → RV。置かれていないカテーテルと、テーマで使えないカテーテルのチャンネルは表示しない。行が多いときは縦スクロール
- **Phase 1 の仮実装の解消（Phase 2）**：両心房を 1 つのシミュレーションで動かすため、HRA は常に RA 上にあり、His の A はメッシュから計算する。カテーテルは 3D 上で配置する（§10）

## 7. アブレーション（`src/core/ablation`）

| エネルギー | デバイス | 操作 | 病変モデル（教育用近似） |
|---|---|---|---|
| RF | 先端 3.5 mm 灌流 | 出力 25〜50 W、時間（〜60 s）、接触圧（先端の押し込みから） | 通電量（出力・接触圧で重みをつけた時間）を積算し、深さは量に対して飽和、半径 = 深さ。病変指標 = 量 / 部位の目標量。球冠の形（中心が最も深い） |
| クライオ | 28 mm バルーン | 標的の PV、押し付け 0〜100 %、PV の軸とのずれ 0〜30°、時間 | 閉塞度 = 押し付け × (1 − ずれ / 30°)。閉塞度 0.8 以上で PV 口の前庭部を一周する帯、未満は漏れのある側に隙間。time-to-isolation を表示 |

**貫壁性**：病変の深さ / 部位の壁厚。1 で伝導遮断（viability 0・電位 0）、1 未満は伝導が遅くなるだけ（viability = 1 − 0.7 × 貫壁性、電位 × (1 − 貫壁性)）。浅い病変を重ねても深い方で決まる（RF・クライオ）。PFA は回数で加算する。

**通電の時計**：病変の成長だけを 1×／5×／10×（既定 5×）で進め、EGM・伝播・体表 ECG は実時間のまま（通電中も電位の変化が見える）。通電時間はシミュレーション時間で表示し、計算が重い症例では実効の倍速（例：「5× 設定・実効 3.5×」）を並べて表示する。

| 接触圧 | 先端の壁からの距離 2 mm（接触の閾値）〜0.5 mm を 0〜40 g に対応 | 非接触は 0 g |
| 局所インピーダンス | 血中 100 Ω、接触で最大 +40 Ω、病変の形成（深さ / 壁厚）で最大 −30 Ω | OPAL HDx 風テーマのみ表示 |
| 病変指標の尺度 | 独自（部位の目標量 = 100 %） | 各社の指標・目標値（400／550 など）は使わない。貫壁性は別に表示する（教育用の推定） |
| クライオの最低温度 | −40 ℃ − 20 ℃ × 閉塞度（閉塞度 1 で −60 ℃）、30 秒で到達 | |
| クライオの深さ | 3 mm × (｜最低温度｜/ 60) × (1 − exp(−時間 / 60 s)) | 閉塞良好で隔離まで 約 40 秒 |
| クライオの帯 | PV 口から LA 側 7 mm、PV 口の外側 6 mm まで（とその PV の口の領域） | 閉塞度 0.8 以上で一周 |
| PFA の病変 | バスケット：PV 口の縁の −2〜+4 mm の輪、フラワー：口から外側 6 mm までの円盤、LA 側 6 mm まで | 1 回で貫壁性 0.5、2 回以上で 1 |
| 接合部調律 | 遅伝導路部位から 5 mm 以内で RF 通電中に、周期 500〜700 ms の接合部の興奮 | 遅伝導路の通電の有効性の目安として表示 |
| His 部位の警告 | His 部位から 5 mm 以内の通電で注意を表示 | 合併症（房室ブロック）は再現しない |

合併症（房室ブロック・PV 狭窄・横隔神経麻痺・食道傷害など）は再現しない。His 部位の近くの通電に注意を表示するだけ。

**注意**：上の式・数値は文献値の目安をもとにした教育用の近似で、各社の製品アルゴリズムとは無関係。画面には「教育用モデル」である旨を常時表示する。

## 9. ジオメトリー作成

### 9.1 プリセットモード

**方針：まずパラメトリック自作、後で公開 3D モデルへ差し替え可能にする。**

- `src/core/geometry/parametric/` で、符号付き距離関数（楕円体・楕円断面の管のなめらかな和）を Surface Nets で三角形メッシュにする（格子 2 mm、辺長の中央値 約 2 mm、頂点 normal 約 5,000・afRemodeled 約 5,900）。緯度経度メッシュと違い、極や継ぎ目ができない
  - LA：楕円体＋PV 4 本（上下径を長軸とする楕円断面の管、口から 15 mm）＋LAA＋僧帽弁輪の開口
  - RA：楕円体＋SVC・IVC＋右心耳＋三尖弁輪の開口＋CS 口
  - 弁輪・静脈の端・CS 口は平面で切り抜いた穴とする
- 頂点ごとの領域ラベル（`src/core/geometry/regions.ts`、31 種。Phase 4 で Bachmann 束の帯と Eustachian 稜、Phase 4 の追補で右心耳を追加）を生成時に付ける。分界稜は SVC の縁から IVC の縁まで、Eustachian 稜は IVC の縁から CS 口まで、RA 表面の線として定義する：LA 本体・中隔・天蓋・後壁・前壁、LAA、僧帽弁輪、PV 4 本のスリーブと口、RA 本体・中隔、卵円窩、洞結節、分界稜、CTI、CS 口、His 束部位、房室結節、遅伝導路部位、三尖弁輪、SVC、IVC。PV のスリーブと口は、軸からの距離を PV の半径で割った値が最も小さい PV に割り当てる（Phase 5：近接する右 PV の管の壁を隣の PV に割り当てないため）
- LA と RA は 1 つのメッシュにまとめ、Bachmann 束・卵円窩縁・CS 筋束の 3 か所を心房間の連結でつなぐ。洞調律で LA に最初に入るのは卵円窩縁（洞結節を分界稜の上端に置いたため。連結はどれも一般心房筋と同じ伝導速度）
- 洞結節は分界稜の上端（SVC と RA の接合部の後外側、方向 (−0.6, 0.75, −0.15)。仮定値）
- 寸法は `src/core/geometry/parametric/dimensions.ts` に集約し、**normal**（AVNRT・WPW）、**afRemodeled**（AF）、**aflRemodeled**（AFL：RA と三尖弁輪を normal の 1.2 倍。RA の中心は短径から決め、LA と食い込まないようにする）の 3 セットをもつ。構造物の向き（PV・弁輪・CS 口などの方向）は `atria.ts` の `ORIENT` にまとめた仮定値（教育用近似）
- メッシュの読み込み口は `ChamberLoader` インターフェース（`src/core/geometry/ChamberLoader.ts`）に統一し、glTF ローダ（公開モデル、Blender で切り出し・ポリゴン削減・ラベル付け）を Phase 7 で追加する。公開モデルを使う場合はライセンス（CC BY など）を `docs/ASSETS.md` に記録する。カテーテル配置などの幾何計算はメッシュだけで行い（`MeshQuery`）、SDF に依存しない

### 9.2 収集モード（FAM 風）
- 隠しメッシュ（プリセット）を「真の解剖」として保持し、ユーザーのカテーテル電極が触れた点を収集する
- 収集点から表示メッシュを段階的に構築（点が少ないときは粗い凸包、増えるにつれて真の形に近づく）
- 内部の電気生理計算は常に隠しメッシュ上で行い、表示メッシュへ投影する。これにより「マップが粗くても電気生理は正しい」状態を保てる

## 10. カテーテル

| 種類 | 電極 | 既定配置 | 用途 |
|---|---|---|---|
| CS 10 極 | 10 | CS 口〜遠位 | 心房活性化順序の基準 |
| His 4 極 | 4 | Koch 三角前上方 | His 電位、AH／HV |
| HRA 4 極 | 4 | 高位右房 | 刺激・記録 |
| RV 4 極 | 4 | RV 心尖 | 心室刺激・記録 |
| 環状（Lasso 風） | 10 | 任意（PV 内では PV を一周） | PV 電位・隔離確認 |
| 多極スプライン／グリッド | 20／16 | 任意 | 高密度マッピング（テーマの機能フラグで出し分け） |
| アブレーション先端 | 4 | LA 側壁 | RF 通電・記録 |
| クライオバルーン | — | 通電欄で選んだ PV の口（AF のみ） | クライオ。押し付けと軸のずれで閉塞度が決まる |
| PFA デバイス | — | 通電欄で選んだ PV の口（AF のみ） | PFA（バスケット型／フラワー型） |

配置の方式（`src/core/catheter/placement.ts`）：

- **経路に沿って動かす**：CS・His・HRA。経路（`guidedPaths.ts`）は CS＝RA 内の CS 口の手前 → CS 口 → 僧帽弁輪の後方に沿って側壁へ（心外膜側）、His＝三尖弁輪の縁を His 部位から後下方へ（遠位電極を弁輪に置き、近位電極は心房中隔側へ並べる）、HRA＝洞結節から RA 側壁を下る経路
- **自由ドラッグ**：ABL・環状・多極。3D 上の点（raycast）に置く
- 操作：カテーテルを一覧で選ぶ → 3D 上でクリック／ドラッグ（経路カテーテルは経路上の最寄り位置へ）。ホイールで押し込み／引き戻し、Shift＋ホイールで回転。操作パネルのスライダーでも同じ操作ができる。選択を解除すると視点を回せる
- 接触判定：電極から表面までの実距離が 2 mm 以下なら接触（`contactVertex` = 最寄り頂点）
- RV は心室メッシュがないため合成のまま（配置操作なし）
