# 既知の単純化と限界

アプリ内「このシミュレータについて」で表示する（このファイルをビルド時に取り込む）。レビューで判明した点を随時追加する。

- 心筋は表面メッシュ（2 次元多様体）として扱い、壁厚・貫壁性は `transmurality` の数値で近似している
- 伝播はセルオートマトンであり、イオン電流・再分極の異方性・ソース–シンク関係は再現しない
- 心室はメッシュを持たず 1 コンパートメントで扱う。体表 ECG の心室成分は拍の種類ごとの電気ベクトルの和（12 誘導）で、心室の興奮の広がりからは計算しない。副伝導路の部位による QRS・デルタ波の違い（局在診断）は扱わない（副伝導路は左側自由壁の 1 か所）。胸部誘導は電気ベクトルの投影に、誘導ごとの経験的な近接補正（QRS と T 波に別の係数。教育用の経験的補正）を掛けて振幅を合わせている。近接電界を計算しているわけではなく、係数は正常洞調律の典型的な振幅（V2〜V4 の R 波 1〜2 mV、移行帯 V3〜V4）に合わせたもので、ほかの拍（ペーシング・早期興奮）の振幅は検証していない
- 病変径は文献値の目安に基づく教育用近似で、各社製品の指標（Ablation Index、DirectSense など）の計算式とは無関係
- 透視・心エコー・自律神経の影響・合併症は扱わない
- EGM は電流源密度近似（φ モデル）で、組織の異方性・血液と組織の導電率の差・電極の大きさは扱わない
- His の H・V 電位、RV 電位、心房カテーテルに乗る心室遠隔電位はタイミングからのテンプレート合成（心室はメッシュを持たない）。His の A は Koch 三角の心房筋から計算する
- 体表 ECG の P 波・粗動波・f 波は、心房の電流源から求めた電気ベクトルを誘導の方向に投影したもの（Phase 4 から）。誘導の方向と振幅の較正は仮定値で、胸郭内の導電率の不均一は扱わない
- 解剖はパラメトリック形状（楕円体と管）で、構造物の向き（PV・弁輪・CS 口など）は仮定値。LAA は湾曲や分葉のない管で近似している
- PV は 4 本が別々に開口する型だけを作る。この型は約 70% で、共通幹などの変異は扱わない（Niinuma H ほか, Europace 2008;10:iii14-iii21）
- 心房間の伝導は Bachmann 束・卵円窩縁・CS 筋束の 3 か所の連結だけで表し、分界稜・Bachmann 束などの優先伝導路は入れていない。代わりに一般心房筋の伝導速度（1.0 mm/ms）を、P 波幅が正常上限（120 ms）を下回るよう調整した。洞調律の P 波幅は normal 約 106 ms・afRemodeled 約 112 ms だが、全頂点の興奮終了（PV スリーブ・LAA の先端を含む）は normal 約 121 ms・afRemodeled 約 127 ms
- EGM の電流源は波面付近に限っており、心房の再分極（Ta 波）は EGM・体表 ECG のどちらにも出ない
- 寸法の多く（弁輪径・静脈径・CS 口径・RA 径など）は出典を確認できていない仮定値で、`docs/DESIGN.md §9.1` の表に明記している
- マップの取得点の注釈は電極の単極電位の差から作り、心室の遠隔電位（合成成分）は含まない。LAT はセルオートマトンの活性化時刻より約 +3 ms 遅れる（±5 ms 以内）
- マップの補間はメッシュの辺をたどる表面距離と逆距離重み付けの簡易法で、実機の補間アルゴリズムとは無関係
- 通常の双極電位では、波面と電極の並びが直交する場所や波面の衝突部位で見かけの低電位が出る（実機でも起こる現象。方向非依存 EGM では出ない）
- 頻拍時の WOI の自動切り替えは、調律が tachycardia と判定されているときだけ働く。刺激中・判定中（頻拍の判定には刺激をやめてから 5 秒ほどかかる）は洞調律の WOI を使う
- AF は「PV トリガーの高頻度発火による不規則な伝導」として表し、複数の興奮波の旋回（multiple wavelet）は持続しない（一般心房筋の波長が LA の周長より長いため）。PVI でトリガーを隔離すると止まる
- 通常型 AFL は、拡大した RA（仮定値）と遅い RA の伝導（0.6 mm/ms）でのみ旋回が持続する。分界稜・Eustachian 稜は完全な機能的ブロック線、大静脈は興奮しないものとして扱う
- 通常型 AFL の粗動波の極性は、AFL の症例だけの心房間の連結（Bachmann 束と CS 筋束を同じ短い時間で渡し、卵円窩縁を置かない。解剖学的な根拠は弱い教育用の設定）で合わせている。反時計回りは下壁誘導で陰性優位（II 1.82・III 2.43・aVF 2.19）、時計回りは II が陽性寄り（0.69）になるが、時計回りの III（1.67）・aVF（1.03）は陽性にならない
- 通常型 AFL の V1 の粗動波は、旋回の向きによらず陰性優位（反時計回り 4.6・時計回り 23.5）。反時計回りの典型的な陽性の V1 は再現できていない（LA の興奮では作れず、RA 側の機序を検討中）
- AFL の症例で、簡易通電のような細い CTI の線（線は完成と判定される）では、IVC 側で線の外側を回り込む粗動（周期長 約 330 ms）が残ることがある。RF の通電（40 W・45 秒）の線では残らない
- 洞調律の V1 の P 波は二相性（+0.07／−0.17 mV）だが、後半の陰性が初期の陽性より大きく、左房負荷のような形に近い
- 洞調律で LA に最初に入るのは卵円窩縁で、Bachmann 束ではない（正常では Bachmann 束経由が最早のことが多い）。心房間の連結はどれも一般心房筋と同じ伝導速度で、優先伝導路を入れていないため
- 心室刺激で房室結節を逆行する伝導（VA 伝導）は扱わない（副伝導路の逆行と、AVNRT の速伝導路の逆行だけ）
- 病変は表面の頂点ごとの貫壁性（深さ / 壁厚）で表し、壁厚は部位ごとの一定値（仮定値）。組織の加熱・冷却・電場の計算はしない。RF の病変の大きさは出力・接触圧・時間から積算する通電量の経験式（臨床経験に基づく教育用近似）で、灌流・カテーテルの向き・血流による冷却・カテーテルの安定性は扱わない。病変指標の後壁／前壁の区分は LA の前後半分で機械的に分けている
- 通電中の浮腫（一時的な伝導遮断とその回復）は扱わない。浅い病変（貫壁性 < 1）は伝導が遅くなるだけで、時間で回復も進行もしない
- 病変指標は本アプリ独自の尺度（部位の目標量 = 100 %、後壁・前壁の 2 区分）で、実機の指標・目標値とは対応しない。指標 100 % が貫壁を意味するとは限らない（CTI の弁輪側など厚い部位では未貫壁）
- クライオバルーンの閉塞度は押し付けと軸のずれだけで決まり、PV の造影・血流は扱わない。PFA の病変の形は模式（バスケット＝輪、フラワー＝円盤）で、電場の分布は計算しない
- 合併症（房室ブロック・PV 狭窄・横隔神経麻痺・食道傷害など）は再現しない。His 部位から 5 mm 以内の RF 通電に注意を表示するだけ
- 接合部調律は遅伝導路部位から 5 mm 以内の RF 通電中に、周期 500〜700 ms で出す規則（VA 逆行ブロックなどの危険な所見は扱わない）
- 通電の時計（倍速）は病変の成長だけを速める。AF の症例では計算が重いため、通電の進みが設定の倍速より遅くなる（画面に実効の倍速を表示する。通電時間はシミュレーション時間）
- 画面上の「非誘発」の確認は、最後の通電の後に利用者が刺激プロトコルを実行して行う（自動では走らせない）
- AF の計算は重く（1 秒ぶんに約 0.4 秒）、性能の低い端末ではシミュレーションが実時間より遅れることがある
- 収集モードの形は、真のメッシュの頂点を「収集済み」にして見せるだけで、実機のように電極の位置から表面を作り直してはいない（収集した部分の形は正確で、呼吸・心拍による動き・カテーテルの押し込みによる変形は扱わない）
- 学習ゴールの判定は軽い条件（構造・出来事）で行う。例：exit block のゴールは「隔離された PV に接触した環状カテーテルから刺激した」ことで判定し、刺激の結果の LA の捕捉の有無までは見ない（モデルでは隔離されていれば LA に伝わらない）
- AFL の旋回方向の読みは、ハローの電極の最後の興奮時刻の位相の順序から判定する。頻拍と判定されてから（刺激をやめて 5 秒ほど）でないと答えられない
- glTF の領域ラベルの半自動推定は、座標系がアプリと同じで、LA に 5 つ・RA に 4 つの開口がある形を前提にする。パラメトリック形状で確かめた一致は主要な領域で 80 % 以上だが、CTI は 65 % 以上（IVC の付け根の推定が 3〜4 mm 深い）、CS 口は 55 % 以上（縁の半径が小さい）にとどまり、洞結節は 8 mm までずれる。左心耳・右心耳・Bachmann 束は推定しない。実際のモデルではラベル JSON での手直しを前提とする
- glTF の開口の中心は縁の輪に当てはめた円の中心で、パラメトリック形状の切断面の中心とは 1〜3 mm 違う（CS 口は 6 mm 程度）
- ハローの電極間隔（2-8-2 mm）と位置は仮定値。時計回りの粗動は別の症例（低位外側 RA からのバーストで誘発）として扱い、根治の基準は反時計回りと同じ（CTI の線と両方向性ブロック）
