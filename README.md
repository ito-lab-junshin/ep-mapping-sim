# EP Mapping Simulator

不整脈アブレーションの **3D マッピング教育シミュレータ**（開発中）。

- CARTO 風・EnSite 風・OPAL HDx 風の画面を切り替えて、同じ症例を見比べられる
- 不整脈：心房細動（PVI）／通常型心房粗動（CTI）／AVNRT（遅伝導路）／WPW・副伝導路
- ジオメトリー：プリセットモデル／カテーテルで点を集めて作る収集モード
- カテーテルを置くと位置に応じた心内心電図が表示され、頻拍を誘発 → アブレーション（RF／クライオ／PFA）→ 停止・非誘発まで体験できる

対象は臨床工学技士の学生と若手メディカルスタッフ。将来は研究用途（伝播モデルの差し替え、パラメータ入出力）へ拡張する。

## 開発

```bash
npm install
npm run dev
```

`main` に push すると GitHub Actions が GitHub Pages へ自動デプロイします（リポジトリ設定 → Pages → Source を「GitHub Actions」にしておく）。
